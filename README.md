## 📋 About

**SCP Studio** (formerly Vectorizer) is the creative conversion engine of the SCP platform. Upload any raster image — PNG, JPEG, WebP — and SCP Studio will intelligently trace and convert it into a perfectly scalable SVG vector. With real-time preview, fine-tuned controls, a credit-based system, and Firebase-powered cloud hosting, it's the ultimate vector conversion experience.

> 🎨 *From pixels to perfection.*

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/koushal124590/scp-studio/scp-studio.git

# Navigate to the project
cd scp-studio

# Install dependencies
npm install

# Open in browser
open index.html
# Or use a local server
npx serve .

# For server-side rendering (Puppeteer)
node app.js
```
